Claude connector

Use Penopta from Claude.ai, Claude Desktop, Claude Code, and Cowork through a remote MCP connector authenticated with Sign in with Penopta.

What it does

The Penopta connector lets Claude verify your workspace connection, list and search projects and threads, pull project context into chat, sync opted-in Claude project transcripts, and track the current conversation on demand.

  • Identity — OAuth (Sign in with Penopta). No API key to paste.
  • Scope — Your active Penopta organization.
  • Privacy — Transcript sync only covers projects you choose to track. Projects named with a P: or Private: prefix are never registered or synced.

MCP server URL

Remote server (Streamable HTTP):
https://app.penopta.com/api/mcp

Install in Claude.ai / Desktop

  1. Open Settings → Connectors.
  2. Prefer Penopta from the Connectors directory when it is listed. Otherwise choose Add → Add custom connector.
  3. Name it Penopta and paste the MCP server URL above if adding custom.
  4. Approve the Sign in with Penopta prompt.
  5. In a new chat, ask Claude to verify the connection (e.g. “Run penopta_verify tool”).

Guided setup inside the product: app.penopta.com/integrations/claude (sign-in required).

Optional hourly sync

To keep Claude.ai project threads flowing into Penopta on a schedule:

  1. Install Claude in Chrome and stay signed in (used to list claude.ai projects and threads).
  2. In the Claude desktop app, create a Skill with the instructions from the Penopta Claude integrations page.
  3. Create an hourly scheduled task that runs that skill.
  4. Run the task once and choose Always allow for Penopta and Chrome tools so unattended runs can finish.

Claude Code / Cowork plugin

For Claude Code and Cowork, install the Penopta plugin (skills + the same remote MCP). The plugin points at this connector so you get context skills without pasting a URL. See the plugin README in the Penopta app repository under plugins/claude/.
